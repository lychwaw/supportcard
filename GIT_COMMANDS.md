# 🚀 Git Commands - After Restarting VS Code

**Restart VS Code first** so Git is available, then run these commands:

---

## Quick Commands:

```bash
# Check if git works
git --version

# Check current status
git status

# Add all changes
git add .

# Commit changes
git commit -m "Add family support system and improve UI"

# Push to GitHub
git push origin main
```

---

## If Repository Not Connected Yet:

```bash
# Initialize git repository
git init

# Add all files
git add .

# Make first commit
git commit -m "Initial commit"

# Connect to your GitHub repo
git remote add origin https://github.com/lychwaw/bluebird-payments-pro.git

# Push to GitHub
git push -u origin main
```

---

## After You Restart VS Code:

**Just copy/paste these commands one at a time:**

1. `git init` (if needed)
2. `git add .`
3. `git commit -m "Add family support"`
4. `git remote add origin https://github.com/lychwaw/bluebird-payments-pro.git` (if first time)
5. `git push -u origin main`

**That's it!** 🎉
